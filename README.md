# Syncrade Visual Constitution v1

**The Canonical Visual Order of a Market Intelligence System**

This is the system's "constitution," not a UI Guide, but the trust order itself.

---

## I. Core Positioning (You Are Not a Tool, You Are Order)

Syncrade's visuals are not for "looking good," but to express:

**This is a system you can entrust your judgment to.**

Not entertainment, not a retail tool, not a KOL page.  
It is a **Market Intelligence Order System**.

Your user psychology is not:

> "Does this look good?"

But rather:

> "Do I dare trust it?"

---

## II. Three Laws of Design Philosophy (Non-negotiable)

### Law 1 — Neutrality First

Visuals must be calm, neutral, low-stimulus, non-positional  
→ Before users "entrust their judgment," they must feel this is a system that does not induce, market, or incite

Therefore, you are never allowed:

| Forbidden | Reason |
|-----------|--------|
| Gradients | Emotional |
| Large color blocks | Marketing feel |
| Bright blue / Fluorescent colors | Web3 gambling feel |
| High saturation primary colors | "Click me" |
| Card shadows | SaaS toy feel |

---

### Law 2 — System Over Product

You are not a product page, you are a system terminal.

Your page must feel like:
- Bloomberg Terminal
- Palantir / Datadog / Stripe Radar
- NASA control console
- Audit system / Risk control system

Not like:
- Crypto Landing Page
- SaaS Dashboard
- Startup Website

---

### Law 3 — Silence is Authority

You do not build trust through "excitement,"  
You build trust through "quiet + restraint + certainty."

**Authoritative systems are always low-voiced.**

---

## III. Visual Skeleton (Only This Set Is Allowed for Your Entire Site)

### 1. Color Constitution

| Role | Value | Usage |
|------|-------|-------|
| Absolute Black | `#0B0E11` | Primary background |
| System Gray | `#1A1F26` | Module background |
| Neutral Line | `#2A313A` | Divider |
| Text Primary | `#E6E9ED` | Body text |
| Text Secondary | `#9CA3AF` | Secondary text |
| Accent | `#6B7280` | Sole accent color |

❌ No brand colors  
❌ No gradients  
❌ No button highlights  
→ Everything restrained

---

### 2. Typography Constitution

| Item | Rule |
|------|------|
| Font | Inter / SF Pro only |
| Weight | 400 / 500 / 600 |
| Headings | No bold, no larger, no color |
| All text | Left-aligned |
| Line height | Large (to keep calm) |

---

### 3. Layout Constitution

Always:

```
┌────────────────────────────┐
│   SYSTEM HEADER            │
├────────────────────────────┤
│   Input / Query Zone       │
├────────────────────────────┤

```

**No cards**  
**No overlays**  
**No animations**  
**No bounces**

You are a judgment system, not a "product."
